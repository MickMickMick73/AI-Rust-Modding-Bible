# The AI Rust-Modding Bible

A beginner's guide to AI-assisted Rust modding — written by a beginner, for
beginners. Two parts, two audiences:

- **[PART-A.md](PART-A.md)** — for you. Why a working mod isn't the same
  thing as a good mod, and what this project actually is.
- **[PART-B.md](PART-B.md)** — for your AI agent. The full technical
  ruleset: real config patterns, real code examples, verified Rust/Oxide/
  Carbon behavior, a submission-readiness checklist. Paste the whole file
  into your AI agent's context before asking it to build or edit a Rust
  plugin, or point it at the raw link below and let it fetch it directly.

## For your AI agent

Raw link (safe to paste directly into a chat, or hand to a tool that can
fetch a URL):

```
https://raw.githubusercontent.com/MickMickMick73/AI-Rust-Modding-Bible/main/PART-B.md
```

## This is a living document

Part B ends with a section on how to extend it. If your own AI-modding
session turns up something new — verified against real behavior, not
guessed — a pull request adding it back is exactly what this repo is for.
